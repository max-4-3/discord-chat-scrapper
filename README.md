# CHAT SCRAPPER

Scrap discord chat given a channel id  
The token is provided within a `.env` file, in the root of repo:

```ini
TOKEN=YOUR_TOKEN
```

> [!NOTE]
> The token is without surrounding quotes

## USAGE
```console
uv run main.py -c <channel_id>
```
You can also checkout `help`:
```console
uv run main.py --help
```
